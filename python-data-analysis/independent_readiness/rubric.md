# Python 独立实践评分规则

本文件只规定可观察结果，不给出实现结构。总分 100，建议 80 分且没有安全/完整性问题才算通过。

## 评分

- 读取和列验证：15 分。路径或缺列错误可定位，输入表没有被悄悄替换。
- 客户清洗：20 分。编号规范化顺序正确，空编号被拒绝，重复编号只保留一条，输入对象保持不变。
- 订单边界：15 分。只统计 `Completed`；缺失、无穷、负数和非数值不会被静默当作有效金额。
- 客户级汇总：20 分。一行一客户；无完成订单客户仍保留；订单数、累计消费和平均值含义正确。
- 质量摘要：10 分。至少有原始客户行数、清洗后客户数、完成订单行数、无完成订单客户数、重复客户编号数。
- 图表和资源：10 分。两个子图、标签/标题可解释、PNG 非空、Figure 已关闭。
- 可复现性和解释：10 分。使用相对路径，脚本可从项目根目录运行，能解释关键清洗规则和结果。

## 结论边界

- 未提交作答：材料具备测评闭环，但个人能力尚未验证；
- 80～100 分：可以独立完成本课程范围内的基础 Python 数据分析流程；
- 60～79 分：能完成部分流程，应按扣分点回到对应章节；
- 低于 60 分：先复习基础清洗、合并和可视化，再重测。
