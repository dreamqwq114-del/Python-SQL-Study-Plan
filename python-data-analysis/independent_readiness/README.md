## 任务

1. 读取两张 CSV，并在读取后验证必需列；路径错误和缺列错误应明确暴露。
2. 清洗客户表：客户编号先转字符串并去除首尾空格，拒绝缺失或空编号，按规范化编号去重，不修改输入对象。
3. 处理订单表：只统计 `Completed`；`quantity` 和 `unit_price` 必须是有限的非负数，非法值不能静默变成 0。
4. 输出一行一客户的分析表，至少包含客户属性、完成订单数、累计消费和平均订单金额；没有完成订单的客户也必须保留。
5. 输出一个质量摘要，至少说明原始客户行数、清洗后客户数、完成订单行数、无完成订单客户数和重复客户编号数。
6. 生成一张包含两个子图的 PNG：城市平均月消费，以及累计消费最高的客户；保存后关闭 Figure。

运行方式（从项目根目录）：

```powershell

```
