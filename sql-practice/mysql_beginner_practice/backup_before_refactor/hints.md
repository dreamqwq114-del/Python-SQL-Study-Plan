# 分层提示

先独立想 5～10 分钟。只看当前题的提示；如果提示 1 足够，就不要继续向下看。本文件只给方向，不给完整 SQL。

- 题 2：提示 1—使用 `WHERE` 数值比较；提示 2—字段是 `salary`。
- 题 3：提示 1—使用 `IS NULL`；提示 2—检查 `manager_id`。
- 题 4：提示 1—使用 `ORDER BY ... DESC`。
- 题 5：提示 1—使用 `COUNT(*)`。
- 题 6：提示 1—`GROUP BY` 状态；提示 2—对每组 `COUNT(*)`。
- 题 7：提示 1—字符串条件写在 `WHERE`。
- 题 8：提示 1—日期用单引号；提示 2—比较 `hire_date`。
