# 独立实践评分规则

本文件只说明评分点，不提供 SQL 结构或答案。

## 总体规则

- 总分：100；
- 通过线：80；
- SQL 能运行但结果不符合题意，不能得到结果正确分；
- 字段、行数、`NULL`、重复或排序未验证时，扣除对应验证分；
- 第 6 题违反安全门槛时，本次测评直接判定“不通过”。

## 第 1 题：10 分

- 返回列正确：2 分；
- 日期和状态条件正确：4 分；
- 预算及并列排序正确：2 分；
- 能说明 `NULL` 和结果范围：2 分。

## 第 2 题：15 分

- 分组列和三个结果列正确：4 分；
- 总项目数正确：3 分；
- 非空结束日期计数正确：3 分；
- 分组后筛选正确：3 分；
- 排序和验证正确：2 分。

## 第 3 题：20 分

- 三张表选择正确：4 分；
- 两个连接条件正确：6 分；
- 无经理项目被正确排除：3 分；
- 每个项目最多一行：3 分；
- 返回列和排序正确：4 分。

## 第 4 题：20 分

- 保留项目的连接方向正确：4 分；
- 不重复参与人数正确：5 分；
- 收益率缺失状态判断正确：4 分；
- “无人参与或收益率缺失”的 `OR` 条件正确：4 分；
- 无重复并且排序正确：3 分。

## 第 5 题：20 分

- 使用非递归 CTE 且内容合理：4 分；
- 项目、部门和指标关系正确：4 分；
- 非空平均收益率计算正确：4 分；
- 严格高于平均值的筛选正确：3 分；
- 管理费空值和标签处理正确：3 分；
- 返回列、重复和排序正确：2 分。

## 第 6 题：15 分

- 修改前确认数据库和目标行：2 分；
- 事务内插入并验证：3 分；
- UPDATE 前预览、精确修改并验证：3 分；
- DELETE 前预览、精确删除并验证：3 分；
- 最终 ROLLBACK 并确认无残留：4 分。

## 第 6 题安全门槛

出现以下任意一种情况，本次测评不通过：

- 当前数据库不是 `mysql_beginner_practice`；
- 执行无 `WHERE` 的 `UPDATE` 或 `DELETE`；
- 操作题目规定以外的数据；
- 执行 `COMMIT`；
- 未执行最终 `ROLLBACK`；
- 运行后固定基线不是 `PASS`。

## 结果解释

- 80～100 且通过安全门槛：可以独立完成本课程范围内的基础 SQL 实践；
- 60～79：具备部分独立能力，按扣分项回到对应章节；
- 0～59：基础尚未形成稳定操作流程；
- 未提交实际作答：材料具备独立实践闭环，个人能力尚未验证。
