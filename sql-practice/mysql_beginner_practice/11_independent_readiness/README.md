# 独立实践测评

这不是新课，也没有 `hints.md`。它用于验证你能否在不模仿示例的情况下，独立完成基础 SQL 实践。

## 开始条件

开始前应完成：

- 第 1～10 章；
- 两个 checkpoint；
- 真正错题的至少一次重做；
- `00_setup/verify_database.sql` 显示 `PASS`。

## 测评规则

- 题目：6 题；
- 总分：100 分；
- 限时：90 分钟；
- 通过线：80 分；
- 第 6 题是安全门槛，违反安全要求时总分达到 80 也不能通过。

## 测评期间可以做什么

- 查看数据库中的表结构和数据；
- 使用 `DESCRIBE table_name;`；
- 运行自己写的查询；
- 检查列、行数、`NULL`、重复、排序和无匹配数据；
- 修改自己的 SQL。

## 测评期间不能做什么

- 打开任何章节的 `hints.md` 或 `answers.sql`；
- 打开本目录的 `answers.sql`；
- 在 90 分钟计时期间打开根目录 `glossary.md`；
- 复制 lesson 示例；
- 查询网络答案；
- 使用 Python、Java 或其他语言代替 SQL；
- 执行无 `WHERE` 的 `UPDATE` 或 `DELETE`；
- 执行 `DROP DATABASE`、`DROP TABLE` 或 `COMMIT`。

## 文件顺序

1. 先运行 `00_setup/verify_database.sql`；
2. 复制 `assessment.sql`，另存为自己的作答文件；
3. 开始 90 分钟计时；
4. 完成后按 `rubric.md` 只检查要求，不看参考 SQL；
5. 把作答文件交给 Codex 或老师评分；
6. 评分完成后才打开 `answers.sql`。

## 结论边界

材料完成并不自动代表你本人已经能够独立完成实践。

- 尚未提交作答：材料具备独立实践闭环，个人能力尚未验证；
- 得分 80～100 且通过安全门槛：可以独立完成本课程范围内的基础 SQL 实践；
- 得分 60～79：能够完成部分实践，但需要针对薄弱章节重做；
- 得分低于 60：暂不建议进入更高级 SQL，应先复习基础章节。
