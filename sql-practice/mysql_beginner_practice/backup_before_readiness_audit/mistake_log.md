# SQL 错题记录

只有真正做错的题才记录。不要提前填写，不要只复制参考答案，必须写清楚自己为什么错。

## 使用规则

- 保留第一次写错的 SQL，不要美化；
- 记录真实报错，或说明结果哪里不符合题意；
- 先写正确思路，再写修正后的 SQL；
- 自己设计一道同类型题；
- 1～2 天后不看答案重新完成。
