# 基础诊断复盘

先独立完成 `00_diagnostic_test.sql`，再核对答案。诊断只帮助你确定复习重点，不会让你跳过后续课程。

## 每题检查什么

1. 能否写出指定列的基础 `SELECT`。
2. 能否用 `WHERE` 做数值比较。
3. 能否正确判断 `NULL`。
4. 能否用 `ORDER BY ... DESC` 排序。
5. 能否用 `COUNT(*)` 统计总行数。
6. 能否理解“按某列分组后计数”。
7. 能否正确写字符串条件。
8. 能否正确写日期条件。
9. 能否根据相同外键写两表 `INNER JOIN`。
10. 能否解释 `= NULL` 为什么错误并改正。

## 如何划分能力

对每一道题按第一次独立完成的情况记录：

- 已掌握：不看提示就写对，并能解释结果。
- 不稳定：看了简短提示后写对，或语法对但结果范围不对。
- 需要重点复习：看提示仍不会、连接条件写错，或只能复制答案。

建议记录：

```text
已掌握：题号 ______
不稳定：题号 ______
需要重点复习：题号 ______
```

即使多数题答对，也按顺序完成第 1～10 天。旧知识会在不同日期重复出现。
